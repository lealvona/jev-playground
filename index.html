Where it fits

The missing AI building block: a decision.

An AI workflow needs a way to turn messy context into a specific next step. Think of JEV-style inference as a decision component between understanding a situation and taking action. “Missing building block” describes its role in an application, not a claim that LLMs cannot make decisions.

Generative LLM · create

Use an LLM to draft code, explain a problem, summarize a conversation, or propose a plan. It generates an answer token by token. LLMs can also return structured decisions.

JEV-style model · choose

Supply the context, a question, and candidate meanings. The decision runtime scores candidate labels and returns a bounded choice or yes/no readout. OpenJev and APUS build on language-model capabilities; the specialization is decision training and inference.

Your application · act

Map the returned key to a workflow. Application code checks permissions and hard rules, requests review when needed, and verifies the outcome. The playground only recommends; it does not deploy, send proposals, or change tickets.

Context + policy + allowed choices → scored decision → application checks → action or review

Easier to connect

Stable choice keys fit routing and workflow branches. Your integration consumes a decision rather than extracting an action from prose.

Less output generation

Candidate scoring avoids generating a long answer for a bounded question. Latency still depends on context length, model, runtime, and hardware; this page measures each actual request.

Flexible decision spaces

Describe new options and policies in the payload. Try a release gate, lead qualification, or project blocker without changing the API shape. Evaluate each new use case with labeled examples.

Know the boundary. This demo uses APUS-OpenJev 4B Q8, a separate model family from the original 27B OpenJev and TypeSafe’s hosted Jev. Scores here are relative preferences, not validated confidence. Missing evidence and poor options can produce a wrong winner; include review or “insufficient evidence” choices where appropriate. Exact business rules belong in code.
